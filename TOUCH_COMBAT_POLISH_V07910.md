# Loot Goblins v0.7.9.10 — Touch + Combat Polish Hotfix

## Based on latest screenshots

### Fixed / improved
- Added iOS selection prevention for game UI and buttons.
  - This should stop blue text-selection handles appearing on buttons like “Take the Hit.”
- Added render/rejoin resilience from v0.7.9.9 remains.
- Added a compact Combat Action Dock.
  - Keeps Pass / Flee / Backup access visible when the hand drawer covers the lower combat controls.
- Reduced collapsed/expanded hand height during combat.
  - Combat should remain more visible while browsing cards.
- Tightened combat board spacing for small phone heights.
- Reduced weight of the top phase strip.
- Reworked Open Chamber door coloring/readability slightly:
  - less generic orange button
  - darker chamber/door feel
  - cleaner label text
- Enlarged private gained-card previews slightly.

## Why
The screenshots showed three recurring problems:
1. iOS was selecting button text.
2. Combat actions could disappear behind the hand drawer.
3. The door and top strip were still reading too much like generic UI.
