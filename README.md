# Loot Goblins v0.5.2 — Core Playability Patch

A three-player browser card-table prototype.

## What changed in v0.5.2

- Parks advanced/manual cards out of the live deck until the v0.6 advanced mechanics pass.
- Automates Steal a Glory with target selection.
- Adds explicit Help Player Side / Help Foe Side buttons for combat one-shot cards.
- Reduces top-header crowding and moves the table center higher in the screen flow.
- Makes combat, flee, and opening roll views more directly centered on the action.

## Deploy

```bash
npm install --package-lock=false
npm start
```
