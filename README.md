# Loot Goblins v0.7.1 — Card Frame + Inspector Redesign

This build keeps the locked v0.6.12 mechanics and the v0.7.0 poker-table layout, then improves card presentation.

## Focus

- Larger main/revealed card in the table center.
- More distinct card frames by type.
- Better compact hand card visual hierarchy.
- Redesigned card inspector as a readable sheet.
- Full rules/flavor/actions remain tap-to-expand.

## Deploy

Use the same Render settings as before:

```txt
Build Command: npm install --package-lock=false
Start Command: npm start
```

## Version

`/health` reports `0.7.1-card-frame-inspector`.
