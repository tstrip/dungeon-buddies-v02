# Loot Goblins v0.7.9.4 — Hand Tray + Combat View Polish

## Changes

### My Goblin badge
- Shrunk the badge again so the hand cards stay visible.
- Empty states now read `Call —` / `Kin —` instead of full `No Calling` / `No Kin`.
- Stats are tighter: `GL1/10 · Gear0`.

### Top phase strip
- Top strip now acts more like a tiny table status label.
- It no longer repeats full instructions like `Your Turn — Open Chamber`.

### No Foe choice buttons
- Start Trouble and Loot the Room now share the same size/shape/visual weight.
- Text is allowed to wrap instead of clipping.

### Combat screen
- Combat Bad News now says `Bad News if you lose`.
- Flee screen still says `Bad News if Flee fails`.
- Bad News text is sentence-cased.
- Collapsed combat hand tray is shorter and less likely to cover the action area.
- Combat drawer copy is reduced.

### Last Chance Before Tribute
- Reworded Use Loot Before Tribute as `Last Chance Before Tribute`.
- Main copy: `Play Loot, equip Gear, trade, or sell Gear.`
- Primary button is now `Check Hand Limit`.

## Not changed
- The yellow browser/menu circle was intentionally ignored because it is from the browser overlay, not the game UI.
